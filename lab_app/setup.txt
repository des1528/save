==========================================================
ИНСТРУКЦИЯ ПО РАЗВЁРТЫВАНИЮ И ЗАПУСКУ ПРИЛОЖЕНИЯ
"Учёт лабораторных анализов"
==========================================================

ТРЕБУЕТСЯ:
- MySQL Server 8.x + MySQL Workbench
- Python 3.10+

----------------------------------------------------------
ЧАСТЬ 1. РАЗВЁРТЫВАНИЕ БАЗЫ ДАННЫХ В MYSQL WORKBENCH
----------------------------------------------------------

1. Запустить MySQL Workbench.

2. Подключиться к локальному серверу:
   - На главном экране нажать "+" рядом с "MySQL Connections".
   - Connection Name: Local
   - Hostname: 127.0.0.1, Port: 3306
   - Username: root
   - Нажать "Test Connection", ввести пароль root.
   - Если соединение успешно — нажать OK, затем дважды кликнуть
     по созданному соединению.

3. Открыть SQL-скрипт schema.sql:
   - File -> Open SQL Script... -> выбрать файл schema.sql
     из папки lab_app.

4. Выполнить скрипт:
   - Нажать кнопку с молнией "Execute (All or Selection)"
     (или Ctrl+Shift+Enter).
   - В нижней панели "Output" должны появиться зелёные галочки
     для каждой команды.

5. Проверить, что база создана:
   - В левой панели "Schemas" нажать кнопку обновления.
   - Должна появиться база lab_db с таблицами:
     users, patients, tests, studies.
   - Правый клик по таблице -> "Select Rows - Limit 1000"
     для просмотра тестовых данных.

6. (Опционально) Построить ERD:
   - Database -> Reverse Engineer... -> выбрать соединение,
     далее выбрать схему lab_db -> Next до конца -> Execute.
   - Откроется EER-диаграмма с тремя связями:
       patients (1) ---< studies >--- (1) tests
                            >---  (1) users

----------------------------------------------------------
ЧАСТЬ 2. ЗАПУСК PYTHON-ПРИЛОЖЕНИЯ
----------------------------------------------------------

1. Открыть командную строку (PowerShell / cmd / терминал)
   и перейти в папку проекта:
       cd путь\к\lab_app

2. (Рекомендуется) Создать виртуальное окружение:
       python -m venv venv
   Активировать:
       Windows:  venv\Scripts\activate
       Linux/Mac: source venv/bin/activate

3. Установить зависимости:
       pip install -r requirements.txt

4. Открыть файл app.py и при необходимости поправить
   параметры подключения к БД (строка DB = ...):
       host='localhost'
       user='root'
       password='root'        <-- заменить на свой пароль root
       database='lab_db'

5. Запустить приложение:
       python app.py

6. В появившемся окне "Авторизация" ввести один из логинов:
       admin / admin
       lab1  / 1234
   Нажать "Войти".

7. Откроется главное окно со списками:
   - Пациенты (из таблицы patients)
   - Анализы — справочник (из таблицы tests)
   - Проведённые исследования (JOIN трёх таблиц)

8. Чтобы добавить новое исследование:
   - Ввести Пациент ID (см. колонку ID в списке пациентов),
     Анализ ID (из справочника), дату ГГГГ-ММ-ДД,
     результат (число).
   - Нажать "Добавить" — запись появится в нижней таблице.

9. Кнопка "Обновить" перечитывает все данные из БД.

----------------------------------------------------------
ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------------------------
- "Access denied for user 'root'" — неверный пароль в DB.
- "Unknown database 'lab_db'" — не выполнен schema.sql.
- "No module named mysql" — не установлены зависимости
  (pip install -r requirements.txt).
- Кракозябры в данных — пересоздать БД, убедиться что
  schema.sql сохранён в UTF-8.
