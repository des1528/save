ВОПРОС 1. Как сгенерировать событие нажатия на кнопку (C#)?

В WinForms кнопка — это объект Button с событием Click. Привязать
обработчик можно тремя способами.

1) Через дизайнер: дважды кликнуть по кнопке на форме — Visual Studio
сама создаст метод button1_Click и подпишет его. В коде Designer.cs
появится строка:

    this.button1.Click += new EventHandler(this.button1_Click);

2) Вручную в конструкторе формы:

    button1.Click += button1_Click;

    private void button1_Click(object sender, EventArgs e)
    {
        MessageBox.Show("Нажато");
    }

3) Лямбдой, без отдельного метода:

    button1.Click += (s, e) => MessageBox.Show("Нажато");

Чтобы программно сымитировать нажатие из кода (без реального клика
мышью), вызывают метод PerformClick():

    button1.PerformClick();

В WPF аналогично, только событие задаётся в XAML атрибутом Click="..."
либо через += в code-behind.


ВОПРОС 2. Назначение методов.

Метод — это именованный блок кода внутри класса, который выполняет
конкретное действие. Нужны для того, чтобы:

- разбивать программу на короткие логические куски (один метод —
  одна задача), иначе весь код превращается в простыню;
- не дублировать одинаковую логику: написал один раз, вызываешь
  из разных мест;
- скрывать детали реализации — снаружи виден только заголовок
  (имя, параметры, возвращаемое значение), внутренности можно
  переписать, не трогая вызывающий код;
- работать с данными объекта: методы класса имеют доступ к его
  полям и меняют его состояние (например, button1.PerformClick()
  внутри класса Button работает с его внутренним состоянием).

Пример: метод Sum складывает два числа и возвращает результат.

    private int Sum(int a, int b)
    {
        return a + b;
    }

    int x = Sum(2, 3);   // 5
    int y = Sum(10, 7);  // 17

Без метода пришлось бы писать a+b в каждом месте, где это нужно.
