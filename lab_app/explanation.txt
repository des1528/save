БЛОК 1. Импорты и параметры подключения
----------------------------------------------------------
КОД:
    import tkinter as tk
    from tkinter import ttk, messagebox
    import mysql.connector

    DB = dict(host='localhost', user='root', password='root', database='lab_db')

НАЗНАЧЕНИЕ:
Подключаются библиотеки для GUI (tkinter) и для работы
с MySQL. В словаре DB централизованно хранятся параметры

ПОСТРОЧНО:
- import tkinter as tk — основная библиотека графического
  интерфейса, доступна в стандартной поставке Python.
- from tkinter import ttk, messagebox — ttk даёт
  современные виджеты (Treeview-таблица), messagebox —
  всплывающие окна с ошибками.
- import mysql.connector — официальный драйвер MySQL
  для Python (устанавливается отдельно).
- DB = dict(...) — словарь параметров подключения,
  передаётся в connect() через распаковку **DB.

БЛОК 2. Функция db()
----------------------------------------------------------
КОД:
    def db():
        return mysql.connector.connect(**DB)

НАЗНАЧЕНИЕ:
Короткая обёртка для открытия нового соединения с БД.
Используется во всех местах, где нужно выполнить SQL-
запрос: это исключает дублирование параметров.

ПОСТРОЧНО:
- def db(): — объявление функции без аргументов.
- mysql.connector.connect(**DB) — создаёт соединение,
  распаковывая словарь DB в именованные аргументы
  (host=..., user=..., и т. д.).

БЛОК 3. Функция login() — обработчик кнопки "Войти"
----------------------------------------------------------
КОД:
    def login():
        c = db()
        cur = c.cursor()
        cur.execute("SELECT id, full_name FROM users WHERE login=%s AND password=%s",
                    (e_login.get(), e_pwd.get()))
        r = cur.fetchone()
        c.close()
        if r:
            root.destroy()
            main(r[0], r[1])
        else:
            messagebox.showerror("Ошибка", "Неверный логин или пароль")

НАЗНАЧЕНИЕ:
Реализует авторизацию. Берёт значения из полей логина и
пароля, ищет совпадение в таблице users. При успехе
закрывает окно авторизации и открывает главное окно,
передавая туда id и имя пользователя (чтобы записывать
в studies.user_id, кто внёс данные).

ПОСТРОЧНО:
- c = db(); cur = c.cursor() — открыть соединение и курсор.
- cur.execute(SQL, (...)) — выполнить параметризованный
  запрос (плейсхолдеры %s защищают от SQL-инъекций).
- e_login.get(), e_pwd.get() — текущий текст из полей ввода.
- r = cur.fetchone() — взять одну строку результата
  (или None, если пользователь не найден).
- c.close() — корректно закрыть соединение.
- if r: — если запись найдена → авторизация успешна.
- root.destroy() — уничтожить окно авторизации.
- main(r[0], r[1]) — открыть главное окно, передав
  id пользователя и его ФИО.
- messagebox.showerror(...) — иначе показать ошибку.

ПОСТРОЧНО:

БЛОК 5. Функция reload() — загрузка данных из БД
----------------------------------------------------------
КОД:
    def reload():
        for tv in (tp, tt, ts):
            for i in tv.get_children(): tv.delete(i)
        c = db(); cur = c.cursor()
        cur.execute("SELECT id, full_name, birth_date, phone FROM patients")
        for r in cur.fetchall(): tp.insert('', 'end', values=r)
        cur.execute("SELECT id, name, unit, norm FROM tests")
        for r in cur.fetchall(): tt.insert('', 'end', values=r)
        cur.execute("""SELECT s.id, p.full_name, t.name, s.study_date,
                       CONCAT(s.result,' ',IFNULL(t.unit,''))
                       FROM studies s
                       JOIN patients p ON s.patient_id=p.id
                       JOIN tests t ON s.test_id=t.id
                       ORDER BY s.id""")
        for r in cur.fetchall(): ts.insert('', 'end', values=r)
        c.close()

НАЗНАЧЕНИЕ:
Очищает все три таблицы и перечитывает данные из БД.
Вызывается при открытии окна, после добавления записи и
по нажатию кнопки "Обновить". JOIN в третьем запросе
демонстрирует работу со связанными таблицами.

ПОСТРОЧНО:
- внешний цикл for tv in (tp, tt, ts) — пробегает по
  трём таблицам и удаляет все строки (get_children()
  возвращает id строк, delete() их удаляет).
- c = db(); cur = c.cursor() — соединение и курсор.
- cur.execute("SELECT ... FROM patients") — простой
  запрос на список пациентов.
- for r in cur.fetchall(): tp.insert('', 'end', values=r)
  — вставка каждой строки в Treeview ('' = корень,
  'end' = в конец).
- запрос к tests — справочник анализов.
- последний запрос — JOIN трёх таблиц: studies + patients
  + tests; CONCAT добавляет к результату единицы измерения,
  IFNULL подставляет пустую строку, если unit = NULL;
  ORDER BY s.id сортирует по id исследования.
- c.close() — закрыть соединение.

БЛОК 7. Функция add() — обработчик кнопки "Добавить"
----------------------------------------------------------
КОД:
    def add():
        try:
            c = db(); cur = c.cursor()
            cur.execute("""INSERT INTO studies
                           (patient_id, test_id, user_id, study_date, result)
                           VALUES (%s,%s,%s,%s,%s)""",
                        (e_pid.get(), e_tid.get(), uid, e_dt.get(), e_res.get()))
            c.commit(); c.close()
            for e in (e_pid, e_tid, e_dt, e_res): e.delete(0, 'end')
            reload()
        except Exception as ex:
            messagebox.showerror("Ошибка", str(ex))

НАЗНАЧЕНИЕ:
Добавляет новую запись в таблицу studies. user_id берётся
из авторизации (uid), а не вводится вручную, что повышает
надёжность данных. После успешного INSERT поля очищаются
и таблица перечитывается.

ПОСТРОЧНО:
- try/except — перехват любых ошибок (неверный формат
  даты, несуществующий patient_id, проблема с БД).
- INSERT с пятью %s — параметризованный запрос
  (защита от инъекций, корректная подстановка чисел/строк).
- uid передаётся напрямую — это id пользователя из
  авторизации.
- c.commit() — фиксация транзакции (без этого данные
  не сохранятся в InnoDB).
- цикл for e in (...): e.delete(0, 'end') — очистка
  всех полей ввода после успешного добавления.
- reload() — обновляет таблицы, чтобы пользователь
  сразу увидел новую запись.
- messagebox.showerror(...) — выводит текст ошибки.

- w.mainloop() — запуск главного цикла Tk: окно ждёт
  события (клики, ввод текста, закрытие).

ВОПРОС 1. Как сгенерировать событие нажатия на кнопку?

В Tkinter событие нажатия на кнопку привязывается через
параметр command конструктора Button:

    tk.Button(parent, text="Войти", command=login)

Здесь login — функция-обработчик, передаётся БЕЗ скобок
(если написать command=login(), функция выполнится сразу
при создании кнопки, а не по клику).

Альтернативный способ — метод bind():
    btn = tk.Button(parent, text="Войти")
    btn.bind("<Button-1>", lambda e: login())
где "<Button-1>" — событие нажатия левой кнопкой мыши.

Программно "нажать" кнопку (сгенерировать событие из кода):
    btn.invoke()
или
    btn.event_generate("<Button-1>")

ВОПРОС 2. Назначение методов.

Метод — это функция, привязанная к классу/объекту.
Назначение методов:
- инкапсуляция поведения объекта (объединить данные
  и операции над ними в одной сущности);
- повторное использование логики через вызов одного
  метода вместо копирования кода;
- сокрытие реализации — внешний код вызывает метод,
  не зная, как он устроен внутри;
- структурирование программы: каждое действие — отдельный
  метод с понятным именем (login(), reload(), add()).

В нашем приложении функции login(), main(), reload(),
add(), db() играют роль методов: каждая решает одну
конкретную задачу, что упрощает чтение и поддержку кода.
